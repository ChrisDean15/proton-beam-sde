This evaluated data file is based on a software system built       925 1451  220
around the nuclear model code TALYS [kon07], version 2.0. It is    925 1451  221
part of a large collection of isotopic evaluations, all created by 925 1451  222
running the system with either adjusted or default input           925 1451  223
parameters. This means that the data in the entire collection have 925 1451  224
been tested in detail for many isotopes against individual         925 1451  225
experimental data, while for other isotopes it is only as good as  925 1451  226
the global quality of TALYS at the moment. The mutual quality of   925 1451  227
all individual data files is however consistent: The same set of   925 1451  228
nuclear models is used and, equally important, the same ENDF-6     925 1451  229
formatting procedures for each isotope. The data file has been     925 1451  230
created automatically using the ENDF-6 format generator TEFAL.     925 1451  231
                                                                   925 1451  232
The resulting data file provides a complete representation of      925 1451  233
nuclear data needed for transport, activation, damage, heating,    925 1451  234
radioactivity, and shielding applications over the incident        925 1451  235
proton energy range from 0.25 to 200. MeV.                         925 1451  236
                                                                   925 1451  237
All transport and activation data for neutrons, charged particles, 925 1451  238
photons and residual nuclides are filed. This includes cross       925 1451  239
sections, angular distributions, double-differential spectra,      925 1451  240
isomeric production, discrete and continuum photon production      925 1451  241
cross sections, residual production cross sections and recoils.    925 1451  242
This general purpose evaluation can thus be used as both           925 1451  243

***************************** T A L Y S ************************** 925 1451  250
                                                                   925 1451  251
TALYS is a computer code system for the prediction and analysis    925 1451  252
of nuclear reactions. TALYS simulates reactions that involve       925 1451  253
neutrons, gamma-rays, protons, deuterons, tritons, helions and     925 1451  254
alpha-particles, in the 1 keV - 200 MeV energy range. This is      925 1451  255
achieved by implementing a suite of nuclear reaction models into   925 1451  256
a single code system. This nuclear data file is based on a         925 1451  257
theoretical analysis that utilizes the optical model, compound     925 1451  258
nucleus statistical theory, fission, direct reactions and          925 1451  259
pre-equilibrium processes, in combination with databases and       925 1451  260
models for nuclear structure. The following output of TALYS is     925 1451  261
stored in this data file:                                          925 1451  262
                                                                   925 1451  263
- Elastic and non-elastic cross sections                           925 1451  264
- Elastic scattering angular distributions                         925 1451  265
- Recoil data                                                      925 1451  266
- Total particle cross sections, e.g. (p,xn), (p,xp),..            925 1451  267
- Total particle energy spectra                                    925 1451  268
- Total particle double-differential spectra                       925 1451  269
- Isomeric and ground state cross sections                         925 1451  270
- Residual production cross sections                               925 1451  271
                                                                   925 1451  272
For a description of the used nuclear models and their             925 1451  273

##### MF33: COVARIANCES OF NEUTRON CROSS SECTIONS                  925 1451  346
                                                                   925 1451  347
In MF33, we store the covariances of most, but not all, reaction   925 1451  348
channels that are given in MF3. All covariances are generated      925 1451  349
with the TASMAN code [kon19], which generates TALYS runs using     925 1451  350
a Monte Carlo parameter method.                                    925 1451  351
For each MT-number, the information consists of:                   925 1451  352
1. Covariances for MTa, Ea and MTa, Ea (variances)                 925 1451  353
2. Covariances for MTa, Ea and MTa, Eb (correlations for the       925 1451  354
   same reaction channel between different energies)               925 1451  355
3. Covariances for MTa, Ea and MTb, Ea (correlations between       925 1451  356
   different reaction channels for the same energy)                925 1451  357
4. Covariances for MTa, Ea and MTb, Eb (correlations between       925 1451  358
   different reaction channels for different energies)             925 1451  359
Classes 1 and 2 are covered by NI-type subsubsections with         925 1451  360
flag LB=5, followed by a LB=8 section which contains               925 1451  361
the cross section variances multiplied by 1.e-3. Next, classes 3   925 1451  362
and 4 are covered by flag LB=6 to account for the different        925 1451  363
energy grids that two correlating MT-sections may have. Since      925 1451  364
the total correlation matrix is fully symmetric, we only need to   925 1451  365
include the correlation elements between different MT-numbers      925 1451  366
once, and we do that in the subsection with the lowest of the      925 1451  367
two MT-numbers. We include covariance information for all the      925 1451  368
total cross sections, the lumped partial cross sections and the    925 1451  369
individual inelastic cross sections per level (MT51,...). We do    925 1451  370
not include covariances for MT600 and higher MT-numbers. For the   925 1451  371
most important channels, we include cross-channel correlations.    925 1451  372
